## 5. How to inspect the artifacts

- Open the GDSII file in a compatible layout viewer such as KLayout.
- Inspect the DEF using tools that support the relevant DEF version and platform.
- SPEF is primarily a parasitic-data exchange format and is most useful with compatible timing-analysis tools and the matching design/library context.
- Read the CSV and reports alongside the exact SDC and platform configuration used in the run.

## 6. Reproducibility and caveats

Physical-design results depend on RTL, constraints, OpenLane configuration, PDK/library files, tool versions, and implementation settings. Re-running the flow may produce different values. The existence of a GDSII file does not by itself establish foundry signoff, silicon fabrication, or hardware validation.
